# D4.2 placement audit (for CP5)

Does each compact element map to the same place in the open card? Compact leading (L) should
map to the card's top-left (TL); compact trailing (R) should map to its top-right (TR). The rule
for this task: a fix may only move an existing element within its card's existing slots. It
may never add or remove one.

Rendered from the checkpoint set at font scale 1.0 (`d4.2-compact-vs-expanded.png`, compact on
the left, open card on the right). FPS, weather and network speed no longer exist.

**Fixes applied: none.** Every mismatch would need a new element, a removed one, or a different
card structure, which this task doesn't allow. The deferred rows need the owner's call at CP5:
keep them as they are, or open a design task.
