How to re-run without losing the app's data (the Gradle connected task uninstalls the app after
the run, which drops its settings and permission grants):
  ./gradlew :app:assembleBenchmark :macrobenchmark:assembleBenchmark
  adb install -r ~/.droidbubble-build/app/outputs/apk/benchmark/Droidbubble-benchmark.apk
  adb install -r ~/.droidbubble-build/macrobenchmark/outputs/apk/benchmark/macrobenchmark-benchmark.apk
  adb shell am instrument -w -r -e class com.droidbubble.macrobenchmark.IslandExpandBenchmark \
      com.droidbubble.macrobenchmark/androidx.test.runner.AndroidJUnitRunner
  JSON: /storage/emulated/0/Android/media/com.droidbubble.macrobenchmark/*-benchmarkData.json
On a spare phone, `./gradlew :macrobenchmark:connectedBenchmarkAndroidTest` does the same.

Needs: the island turned on, the overlay permission (the test grants it by appops) and the
accessibility service already enabled. Leave the phone alone during the run (about 4 minutes).
Afterwards the island is empty until something new shows on it: the benchmark restarts the app.

Fallback without the module: adb shell dumpsys gfxinfo com.droidbubble.app framestats
